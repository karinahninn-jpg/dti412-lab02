Git Command Cheat Sheet
 
1. Check Git Version
 
git --version
 
Purpose: Check the installed Git version.
 
2. Configure Username
 
git config --global user.name "Your Name"
 
Purpose: Set your Git username.
 
3. Configure Email
 
git config --global user.email "karinahninn@gmail.com"
 
Purpose: Set your Git email address.
 
4. Display Configuration
 
git config --list
 
Purpose: Show Git configuration information.
 
5. Clone Repository
 
git clone repository-url
 
Purpose: Download a GitHub repository to your computer.
 
6. Check Status
 
git status
 
Purpose: Display file status.
 
7. Add Files
 
git add .
 
Purpose: Add modified and new files to the staging area.
 
8. Commit Changes
 
git commit -m "message"
 
Purpose: Save changes locally with a message.
 
9. Upload to GitHub
 
git push
 
Purpose: Upload local commits to GitHub.
 
10. Download Updates
 
git pull
 
Purpose: Download and integrate changes from GitHub.
 
11. View Commit History
 
git log --oneline
 
Purpose: Display project commit history.
 
12. Create Branch
 
git branch branch-name
 
Purpose: Create a new branch.
 
13. Switch Branch
 
git checkout branch-name
 
Purpose: Switch to another branch.
 
14. Merge Branch
 
git merge branch-name
 
Purpose: Merge another branch into the current branch.
